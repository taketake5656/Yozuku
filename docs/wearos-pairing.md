# Wear OS ワイヤレス ADB ペア設定ガイド

**日本語** | [English](wearos-pairing.en.md)

Wear OS 5 以降のデバイスで、ペア設定をして `shizuku_server` を起動する手順です。

## ペア設定の手順

1. 開発者向けオプションを有効にします: **設定 → システム → デバイス情報 → ソフトウェア情報** を開き、**ソフトウェア バージョン** を 7 回タップします。
2. **設定 → 開発者向けオプション** で、**ADB デバッグ** と **ワイヤレス デバッグ** を有効にします。
3. **ワイヤレス デバッグ → 新しいデバイスとペア設定** を開きます。画面をオンにしたまま、ペア設定コードを表示しておきます。
4. Yozuku を開いて **ペア設定** を選び、表示されているポートと 6 桁のペア設定コードを入力します。
5. **ワイヤレス デバッグ** のメイン画面に戻り、現在の接続用のポートを確認して、Yozuku で **起動** を選びます。

## トラブルシューティング

| 症状 | 考えられる原因 | 対処 |
| :--- | :--- | :--- |
| TLS / SSL のハンドシェイクのエラー | ADB の RSA 鍵の古い承認が残っている | **開発者向けオプション → USB デバッグの承認を取り消す** を実行し、ウォッチを再起動して、もう一度ペア設定を行います |
| バックグラウンドでサービスが初期化されない | OS の電池の最適化やアプリのスタンバイによる停止 | Yozuku の電池の使用を **制限なし** にします |
| 接続がタイムアウトする | ウォッチが Wi-Fi から切断されている、またはポートが違う | Wi-Fi に接続されていることを確かめ、ワイヤレス デバッグの現在のポート（ペア設定用のポートではない）を確認します |
